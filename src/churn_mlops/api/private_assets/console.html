PREPARACIÓN COMERCIAL · V2.7

Preparar un piloto para empresas SaaS

El modelo actual continúa entrenado con datos de telecomunicaciones. Esta nueva fase define cómo evaluar la calidad de datos de suscripciones antes de entrenar y validar otro modelo. No hay predicciones SaaS comerciales ni carga de CSV en este panel.

1 · Definir abandonoCancelación en los próximos 30 días a partir de una fecha de corte.
2 · Preparar datos históricosIdentificador opaco, fecha de corte, antigüedad, MRR, licencias, actividad y soporte.
3 · Evitar fugas temporalesEvaluar por periodos cronológicos y comprobar que las etiquetas tengan 30 días observados.
4 · Validar antes de venderComprobar calidad, permisos, seguridad y rendimiento del futuro modelo en clientes SaaS reales autorizados.

El repositorio incluye un comprobador local y sin conexión con 240 cuentas inventadas y 12 fechas. Solo informa de preparación estructural; no entrena un modelo ni certifica el RGPD.

PYTHONPATH=src python scripts/check_saas_pilot.py --demo --as-of 2026-03-01

Documentación: docs/saas-pilot-readiness-v27.md. No envíes datos reales al navegador ni a la demo pública.

EXPERIMENTO OFFLINE · V2.8

Primer modelo de churn SaaS con ejemplos inventados

La nueva prueba experimental genera 1.200 cuentas ficticias, entrena una regresión logística y la compara con una línea base de prevalencia usando una partición cronológica. Evalúa ROC-AUC, PR-AUC, precisión, recall y calibración.

No es una predicción SaaS comercial. La etiqueta de abandono proviene de una regla artificial. El modelo no se ha publicado, no se guarda como artefacto y no sustituye al modelo Telco.

$env:PYTHONPATH="src"; python scripts/run_saas_experiment.py --demo

El comando se ejecuta en PowerShell con las dependencias Python del proyecto. No envía datos ni resultados al navegador. Guía: docs/saas-synthetic-experiment-v28.md.

PIPELINE DE EVALUACIÓN LOCAL · V3.0

Evaluar un dataset histórico SaaS sin subirlo a la plataforma

Ahora puedes ejecutar un modelo exploratorio con el contrato de ocho columnas. Valida la calidad y madurez de las etiquetas, separa entrenamiento, validación y prueba por fecha, comprueba una separación de 30 días entre particiones y compara el resultado frente a una línea base.

Primero prueba con las 1.200 cuentas ficticias:

$env:PYTHONPATH="src"; python scripts/evaluate_saas_pilot.py --demo --as-of 2026-03-01

El CSV local solo debe utilizarse con autorización y controles adecuados. No escribas información personal, no subas CSV a GitHub/Render ni compartas el archivo en el chat. El comprobador no verifica la legalidad, la procedencia ni la calidad real de los datos.

Documentación de la evaluación offline: docs/saas-offline-pilot-v30.md. No se publica ningún predictor SaaS ni se guardan modelos o predicciones individuales.

CALIDAD Y ROBUSTEZ · V3.1

Comprobar calidad de datos y sensibilidad del modelo

El informe offline añade estadísticas agregadas por partición y avisos orientativos de cambios en distribuciones. Los valores faltantes o inválidos se rechazan antes del entrenamiento: no se rellenan silenciosamente.

También simula en validación solamente tres escenarios hipotéticos: 5 días menos de actividad, 2 incidencias adicionales y un MRR un 20 % menor. No se ajusta el modelo usando el test ni se atribuyen cancelaciones evitadas.

Para leer un resumen corto de los resultados ficticios:

$env:PYTHONPATH="src"; python scripts/evaluate_saas_pilot.py --demo --as-of 2026-03-01 --format text

El reporte completo en JSON sigue disponible por defecto. El PSI es una señal orientativa de cambio de distribución, no una prueba de estabilidad en empresas reales. Guía: docs/saas-data-quality-v31.md.
